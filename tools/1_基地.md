# 工具 1｜基地

## 這個工具給你什麼

一個**會記憶、有地圖的工作台資料夾**。裝完之後：

- AI 每次開場自動認得你（不用重新自我介紹）
- 每件事有自己的資料夾，AI 知道你在做哪些事、各做到哪
- 你糾正過的事、講過的偏好，會被寫下來，下次還記得
- 做完一件事 AI 自己收尾：留紀錄、更新進度、存一版，改壞了回得去

> 背後的原理一句話：AI 其實每次開新對話都是失憶的。它會越來越懂你，不是因為記性好，而是因為你把記憶蓋在資料夾裡——它進門第一件事就是讀你留給它的東西。

## 需要先有什麼

- 工具 0（AI 能開資料夾）

## 施工步驟（給 AI 照做）

### 1. 訪談，只問三題

1. 「你大概在做什麼？如果是公司或團隊，大概多大規模？」
2. 「你現在最想讓 AI 幫你解決什麼問題？」（這題的答案會變成第一個專案）
3. 「你希望 AI 跟你合作時是什麼風格？（例如：直接講重點／多解釋一點／做之前先問我）」

他回答後，用一兩句白話複述確認。**不要做身家調查**，三題就好，其他以後用到再問。

### 2. 蓋資料夾

**總基地＝你現在開著的這個資料夾**（使用者自己建、選給你的家），直接在這裡面蓋，**不要再往下多建一層 `AI工作台/`**。原因：AI 只會自動讀「開著的資料夾」和它上層的家規；多包一層，他每次照常打開這個資料夾時，AI 就讀不到家規、認不得他了。
（只有在你沒開著任何資料夾、例如網頁版時，才請他建一個新資料夾當家。）

下面的 `<家>` 就是這個資料夾，名字照他取的：

```
<家>/                         ← 總基地（他選給你的那個資料夾）
├── CLAUDE.md                 ← 家規（給 Claude 自動讀）
├── AGENTS.md                 ← 家規（給 Codex 自動讀，內容與 CLAUDE.md 相同）
├── README.md                 ← 地圖：有哪些專案、各在做什麼、狀態、下一步（AI 維護）
├── memory/
│   └── MEMORY.md             ← 記憶索引
├── CHANGELOG.md              ← 工作台本身的紀錄（裝了什麼工具）
├── 裝備清單.md               ← 這個工具包的安裝紀錄
├── 工具包/                   ← 這份工具包的原文（已經在了，不用動）
└── <第一個專案>/             ← 用訪談第 2 題取名，例如「排班表」
    ├── README.md             ← 這個專案要做什麼、為什麼開始、做到哪、下一步
    └── CHANGELOG.md          ← 這個專案做過什麼的流水帳
```

⚠️ **家規檔名必須就叫 `CLAUDE.md` 和 `AGENTS.md`，不能取別的名字。** Claude Code 開場只自動讀 `CLAUDE.md`、Codex 只自動讀 `AGENTS.md`——取別的名字，「進門自動認得你」就失效了。兩份內容保持一樣，改一份就同步另一份。

⚠️ **總基地和專案分兩層，這是整套能運作的關鍵。** 總基地放「你是誰、怎麼合作」；每一件會一直回來做的事，開一個自己的專案資料夾。AI 從專案資料夾開對話時，會自動往上找到總基地的家規，兩層都讀得到。

### 3. 寫家規（用訪談答案填，寫完唸給使用者確認）

範本（`CLAUDE.md` 與 `AGENTS.md` 都用這份，照抄、不要精簡）：

```markdown
# 我的 AI 工作台家規

## 我是誰
（訪談第 1 題的答案，兩三行）
- 電腦：Mac 或 Windows（你自己查，不用問我）

## 我目前最想解決
（訪談第 2 題的答案）

## 合作方式
（訪談第 3 題的答案）

## 這個工作台怎麼走（開工規則）
- 這個資料夾是總基地。每一件會一直回來做的事，開一個自己的資料夾（專案），
  裡面有 README.md（要做什麼、為什麼開始、做到哪、下一步）和 CHANGELOG.md（做過什麼）。
- 總基地的 README.md 是地圖：每個專案一行，寫在做什麼、狀態、下一步。
  開新專案就加一行，狀態變了就改，由你維護，不等我提醒。
- 開工先讀：這份家規 → memory/MEMORY.md → 總基地 README.md 地圖 → 要做的那個專案的 README.md。
  我沒說要做哪個專案、你又判斷不出來，就問我一句。
- 從哪個資料夾開對話都可以。記憶一律寫進總基地的 memory/，專案裡不另開記憶。
- 我丟一件新的事給你：先判斷是已有專案的延伸，還是新專案。新的就開資料夾、寫 README
  （為什麼開始那段用我的原話），並在地圖加一行。

## 讓自己越來越好用（給 AI 的常駐規則）
- 當我糾正你、或講出一個做事偏好時，主動問我：「這條要不要記下來？」
  我同意，就寫成一個檔案放進總基地的 memory/，並在 memory/MEMORY.md 加一行索引。
- 每次開場，先看 memory/MEMORY.md 有哪些記憶，碰到相關的事再打開對應檔案。

## 完工（做完一件事就自動做，不用我喊）
- 做完而且真的試過能用，才算完工。還沒完就在專案 README.md 寫「做到哪、下一步是什麼」，不要說做好了。
- 完工時做四件事：專案 CHANGELOG.md 最上面加一段（日期、做了什麼、為什麼）；
  更新專案 README.md 的「做到哪／下一步」和總基地地圖的狀態；用 Git 存一版；
  有裝知識庫的話，照知識庫的規則多做一步。
- 同一件事只收一次，小修改不用每次都跑。

## 回報前先自問三題
- 有什麼風險？有什麼漏掉？還有什麼沒親眼驗過？
- 三題都答得出來才說「做好了」；沒驗過的要講清楚，不要用「應該可以」帶過。

## 先問我再做
- 碰到錢（付費、訂閱、任何會產生費用的服務）
- 刪除或覆蓋我的檔案
- 對外發送任何東西（訊息、郵件、發佈上網）
```

最後那段「先問我再做」是這個工具包作者用真金白銀換來的預設值，先照放；使用者想改再改。

### 4. 建記憶區、地圖、第一個專案

- `memory/MEMORY.md` 初始內容：`# 記憶索引\n\n（還沒有記憶。之後每記一條，在這裡加一行：- [標題](檔名.md) — 一句話摘要）`
- 工作台 `CHANGELOG.md` 第一段就寫今天：裝了基地、日期。
- **第一個專案**：用訪談第 2 題開資料夾（名字白話，例如「排班表」）。`README.md` 照這個格式：

```markdown
# <專案名>

## 要做什麼
（第 2 題的答案）

## 為什麼開始
（使用者的原話。這段很重要，半年後回頭看才知道當初為什麼要做）

## 做到哪
剛開始，還沒動工。

## 下一步
（跟使用者確認第一步要做什麼，例如：先弄清楚誰要用、現在怎麼做的）
```

  專案 `CHANGELOG.md` 第一段：日期、「開專案」。

- **地圖 `README.md`**（總基地）：

```markdown
# <家> 地圖

| 專案 | 在做什麼 | 狀態 | 下一步 |
|---|---|---|---|
| <專案名>/ | （一句話） | 剛開始 | （第一步） |

- 知識庫/：（裝了工具 2 才有）
- memory/：AI 的記憶，不用自己看
- 工具包/：AI 工具包原文，不用自己看
```

  狀態只用四種：剛開始、進行中、暫停、完成。

### 5. Git 時光機

1. 檢查電腦有沒有裝 Git（你自己跑 `git --version`，不要叫使用者去打指令）。沒裝的話，先白話說明 Git 是「檔案的時光機」，再照他的電腦帶：
   - **Mac**：第一次執行 `git` 時，畫面會跳出「要安裝命令列開發者工具嗎？」→ 先跟他講會跳這個、請他按「安裝」，要等幾分鐘。裝好後你再跑一次 `git --version` 確認。
   - **Windows**：帶他到 Git 官網（git-scm.com）下載安裝，選項全部用預設、一路按下一步；查當下官方說明，不憑記憶指路。裝完你可能要請他開一個新對話才抓得到。
   - 卡住超過幾分鐘 → 先記進裝備清單「待辦」，不擋路，其他步驟照做。
2. 有 Git → 在總基地 `git init`。**新電腦還沒設過名字，第一次存檔會失敗**，所以先只在這個資料夾設定：`git config user.name "<他的名字>"`、`git config user.email "<他的名字>@local"`（不用真的 email，也不要加 `--global`）。然後把剛建的檔案做第一次 commit：「基地落成」，並用 `git log --oneline` 確認真的存進去了。
3. 跟使用者講一句就好：「以後每個階段我都會拍一張快照，改壞了隨時回得去。」細節不用教。

### 6. 建裝備清單

`裝備清單.md`：

```markdown
# 裝備清單

工具包版本：2026-11-04

- [x] 0 環境（YYYY-MM-DD）
- [x] 1 基地（YYYY-MM-DD）
- [ ] 2 知識庫
- [ ] 3 部署

## 待辦
（例如：Git 還沒裝）
```

## 驗收（一定要真的做）

測兩件事，都要真的開新對話：

1. **AI 認得他**：請使用者開一個全新對話（Claude 桌面版按新工作／新對話，資料夾一樣選這個家），問：「你知道我是誰、我在做什麼嗎？」AI 不需要任何提醒就答得出家規裡的內容。新手不熟按鈕的話，一步一步帶他找。
2. **AI 走得到專案**：再開一個全新對話，這次**在專案資料夾**開（或在總基地開、直接說專案名），問：「這個專案要做什麼？做到哪？下一步是什麼？」AI 答得出專案 README 的內容。

兩題都過 → 基地活了。答不出來 → 檢查檔名是不是正確（`CLAUDE.md`／`AGENTS.md`）、資料夾是不是選對、專案 README 有沒有寫。

## 裝完之後

- 以後每件事都在它自己的專案資料夾裡做；新的事跟 AI 講，它會開新專案、加進地圖。
- 家規不是寫完就死的：AI 被糾正就會問「要不要記下來」，基地會自己越長越懂你。

驗收通過後，跟使用者說：「工具 1 裝好了。今天到這裡，還是繼續裝工具 2（知識庫）？」
