# 工具 2｜知識庫（你的第二大腦）

## 這個工具給你什麼

一個**會自己長大的 Obsidian 知識庫**。不是空白軟體，是開箱就有三個分區、一個首頁、一份放東西的規則——而且接上基地之後，它會自己長：

- 你跟 AI 做完一件事，AI 會判斷「這次有沒有值得留的做法、決定、坑」，有就寫進去。你不用記得要寫筆記。
- 網路上看到好文章，按一下就存進來。
- 收進來的東西累積多了，AI 開場會順手問你要不要整理，不用你記得。

跟基地的分工：**基地記「工作」**（做過什麼、怎麼合作），**知識庫記「學到什麼」**（為什麼這樣做、下次別再踩的坑、做過的決定）。

> 背後三條原則（這套方法的地基，寫進規則裡、人和 AI 都守）：
> 1. **原文不動**：外面收進來的、你自己寫的，AI 永遠不改寫，只能另外提煉。
> 2. **AI 只長「整理好的」**：提煉層會越來越厚，原料層保持原樣。
> 3. **問完存回**：你問 AI 一個問題、得到有用的答案，答案要沉澱回知識庫，下次不用再問一次。

## 需要先有什麼

- 工具 1（基地）
- Obsidian（免費軟體；還沒裝的話施工時一起裝）

## 施工步驟（給 AI 照做）

### 1. 裝 Obsidian（已裝就跳過）

帶使用者到 Obsidian 官網下載安裝（免費，不用註冊帳號也能用）。安裝方式查當下官方說明，不憑記憶指路。

### 2. 把知識庫蓋在基地裡

在工作台資料夾底下建 `知識庫/`（好處：跟基地一起備份、一起進 Git 時光機）：

```
AI工作台/
└── 知識庫/
    ├── 首頁.md          ← 目錄，從這裡出發；最下面記「上次整理」日期
    ├── 規則.md          ← 什麼東西放哪裡、長什麼樣（人和 AI 都要讀）
    ├── 收進來/          ← 外面撿的：文章、影片重點、別人給的資料（原文不動）
    ├── 我寫的/          ← 自己的原始紀錄：會議、想法、決定的原文（原文不動）
    └── 整理好的/        ← 提煉層，只有這裡會長大，分三種：
        ├── 做法/        ← 一件事怎麼做、為什麼這樣做
        ├── 決定/        ← 一個決定的來龍去脈
        └── 踩過的坑/    ← 撞過一次就不想再撞的事
```

`規則.md` 範本（照抄，不要精簡）：

```markdown
# 知識庫規則

## 三條地基
- 收進來/ 和 我寫的/ 是原料，原文永遠不改寫；要提煉就另外寫進 整理好的/。
- 只有 整理好的/ 會長大，一篇講一件事，篇名讓半年後的自己看得懂。
- 問 AI 得到有用的答案，要存回 整理好的/，下次不用再問。

## 整理好的/ 只有三種，照格式寫
- 做法/<這件事叫什麼>.md：為什麼做 → 現在怎麼做（永遠寫最新的樣子，改版就改寫，不堆疊）→ 取捨 → 改版紀錄（一版一行、附日期）
- 決定/YYYY-MM-DD-<議題>.md：問題 → 想過哪些選項 → 結論 → 接下來誰做什麼 → 哪些是 AI 推的、不是我親口說的
- 踩過的坑/<一句話說這個坑>.md：症狀 → 原因 → 下次怎麼避開
- 相關的筆記用 [[檔名]] 連起來，讓知識長成網。

## 給 AI 的規則
- 完工時（做完一件事、真的試過能用），判斷這次有沒有新的做法、改了做法、做了取捨、踩了坑。有才寫，沒有不硬寫；一篇一件事，寫完在 首頁.md 加上連結。
- 寫的內容從對話裡自己整理，不回頭問我已經講過的事。我沒講到的，推一個最可能的版本，標「AI 推論」。
- 每次開場，看 收進來/ 有沒有超過 5 篇還沒整理、或 首頁.md 的「上次整理」距今超過 7 天。有就問一句：「收進來的累積了 N 篇，要不要花兩分鐘整理？」我說好就整理，說不用這次就不再問。
- 「整理知識庫」怎麼做：讀 收進來/ 和 我寫的/ 裡還沒消化的，先跟我確認哪些值得留，再提煉成 整理好的/ 的其中一種；原文留在原地不動；更新 首頁.md 的清單和「上次整理」日期。
```

`首頁.md` 初始內容：

```markdown
# 知識庫首頁

- 收進來/：外面來的原料
- 我寫的/：我自己的原始紀錄
- 整理好的/：提煉過的重點（做法／決定／踩過的坑）

## 做法
（還沒有）

## 決定
（還沒有）

## 踩過的坑
（還沒有）

---
上次整理：YYYY-MM-DD（今天的日期）
```

### 3. 讓 Obsidian 認得它

帶使用者打開 Obsidian → 「開啟資料夾作為儲存庫」→ 選 `AI工作台/知識庫/`。

### 4. 跟基地接線（最重要的一步，少了這步知識庫就是死的書架）

在 `CLAUDE.md` 和 `AGENTS.md` 家規裡追加這一段（兩份都要，內容一樣）：

```markdown
## 知識庫
- 這個工作台有知識庫，在 知識庫/。放東西前先讀 知識庫/規則.md，照它的三種格式寫。
- 完工時多做一步：判斷這次有沒有值得留的做法、決定、踩過的坑，有就寫進 知識庫/整理好的/ 並掛上 首頁.md。
- 每次開場先做一件事，再回答我的問題：數 知識庫/收進來/ 有幾個檔案（不含 .gitkeep），看 知識庫/首頁.md 最下面的「上次整理」日期。超過 5 個、或距今超過 7 天，就先問一句「收進來的累積了 N 篇，要不要花兩分鐘整理？」再回答我原本的問題。我說不用，這次對話就不再問。
- 當我說「整理知識庫」，照 知識庫/規則.md 的做法跑一輪。
```

⚠️ 開場提醒那條一定要把數字（5 篇、7 天）直接寫在家規裡，不能只寫「照規則.md 檢查」。實測過：只寫轉一手，AI 回答小問題時就跳過了。

追加完，唸給使用者聽一次：「以後你做完事，AI 會自己判斷要不要記；收進來的東西多了，它會開場問你一句。你不用記得寫筆記。」

### 5. 寫下第一篇（不留空庫）

當場示範，寫一篇**決定**：「為什麼今天裝知識庫」。問題、選項、結論、接下來，從剛才的對話裡自己整理，使用者沒講到的標「AI 推論」。存進 `整理好的/決定/`，掛上首頁。讓使用者親眼看到一篇筆記從無到有，也看到「AI 推論」長什麼樣。

### 6. 接上瀏覽器（Obsidian Web Clipper，一鍵剪文章）

跟使用者講一句就好：「裝完這個，以後在網路上看到好文章，按一下就存進知識庫，不用複製貼上。」

⚠️ 這段的對象是**完全新手**：一步只做一件事，每步都等他說「好了」再往下，不要一次丟五個步驟。介面按鈕文字會隨版本變，卡住就以官方頁面當下的畫面為準、白話翻給他聽。

1. **裝擴充功能。** 請他用平常上網的瀏覽器打開這個網址（獨立唸給他、或請他自己打）：

   https://obsidian.md/clipper

   頁面上按「Add to Chrome」（用 Edge／Safari／Firefox 的話，往下捲有 More browsers 區、選自己的那顆）→ 跳到擴充功能商店後按「加到 Chrome」→ 跳出確認視窗按「新增擴充功能」。
2. **把它釘出來，不然下次找不到。** 瀏覽器右上角的**拼圖圖示**點開 → 找到 Obsidian Web Clipper → 按旁邊的**圖釘**。之後工具列會一直看得到 Obsidian 的小圖示。
3. **設定存去哪（只要做這一次）。** 點那個小圖示 → 找**齒輪（設定）**：
   - Vault（儲存庫）：填 Obsidian 裡開的儲存庫名稱，照第 3 步裝的預設就是 `知識庫`。
   - 存放位置（Note location）：填 `收進來`。
   - 其他設定都不用動。
4. **實剪一篇。** 請他隨便開一篇網路文章（新聞、部落格都行）→ 點小圖示 → 按儲存。第一次會跳出「要開啟 Obsidian 嗎？」→ 按允許。⚠️ 前提：Obsidian 要開著（或至少開過這個儲存庫一次），沒開就先開。
5. **回 Obsidian 看。** `收進來/` 裡多了那篇文章 → 通了。沒出現 → 回設定檢查儲存庫名稱是不是打錯字（要跟 Obsidian 左上角顯示的一模一樣）。

### 7. 當場示範一次「整理知識庫」

用剛剪進來的那篇當教材，真的跑一次給使用者看：

1. 請使用者跟你說：「整理知識庫」。
2. 你照規則做：讀剛剪的那篇 → 問他「這篇值得留嗎？重點是什麼？」→ 提煉成 `整理好的/` 其中一種（通常是做法）→ 掛上首頁 → 更新「上次整理」日期。
3. 跟他講清楚這個習慣：「以後看到什麼就剪什麼，不用整理；累積多了我開場會問你一句，你說好我就整理。」

### 8. 收尾

- `CHANGELOG.md` 加一段：今天裝了知識庫。
- 更新 `裝備清單.md`。
- 在工作台 `git add 知識庫 CLAUDE.md AGENTS.md CHANGELOG.md 裝備清單.md`、commit：「知識庫落成」。

## 驗收（一定要真的做，測的是「它記得為什麼」，不是「資料夾建好沒」）

1. 使用者打開 Obsidian，看得到首頁、三個分區、第一篇筆記；點首頁連結能跳過去。
2. 在瀏覽器剪一篇文章，`收進來/` 真的出現它。
3. **關鍵測試**：請使用者把目前對話關掉，在工作台開一個全新對話，問 AI：「我上次決定了什麼？為什麼？」AI 不需要任何提醒就答得出第 5 步那篇決定的內容 → 知識庫活了。答不出來 → 檢查家規第 4 步那段有沒有真的寫進 `CLAUDE.md`／`AGENTS.md`、首頁有沒有掛上連結。

## 裝完之後

- 平常不用刻意「寫筆記」：看到好東西就剪；跟 AI 做完事，它自己判斷要不要記；收進來的多了，它開場會問。三件事都不用你記得。
- 真的想手動整理，跟 AI 說一聲「整理知識庫」就好。
- 問使用者：「今天到這裡，還是繼續裝工具 3（部署）？」
