# AI 工具包｜從 0 到 3，把 AI 裝進你的工作裡

這不是教學，是一個**工具包**。

裡面有 4 個工具，每裝一個，你的資料夾裡就多一個真的在運作的東西。裝完之後，你的 AI 會認得你、記得做過的事、改壞了回得去——而且一次比一次更懂你。

這套做法由一位非工程師的餐飲業老闆實測整理：他用同一套方法經營十家店的日常營運。你拿到的是通用版，跟他的行業無關，任何工作都能用。

## 你只要做兩件事

1. 下載這個 repo（按綠色 `Code` → `Download ZIP`，解壓縮）。
2. 把 [`START_HERE.md`](./START_HERE.md) 丟給你的 AI（Claude Code 或 Codex），然後說：

   > 照這份帶我裝工具。我是新手。

AI 會問你「今天想裝哪一個」，然後陪你把它裝好。**一次裝一個就好**，不用趕。

## 四個工具

| # | 工具 | 裝完你多了什麼 |
|---|---|---|
| 0 | 環境 | 一台能跟 AI 一起做事的電腦 |
| 1 | 基地 | 一個會記憶的工作台資料夾——AI 進門就認得你、做過的事有痕跡、改壞了回得去 |
| 2 | 知識庫 | 一個會自己長大的 Obsidian 知識庫：做完事 AI 自動把值得留的做法、決定、坑寫進去；瀏覽器看到好文章一鍵存進來；累積多了 AI 開場提醒你整理 |
| 3 | 部署 | 你的第一個「有網址的作品」，別人的手機打得開 |

順序照 0 → 1 → 2 → 3 裝最順（後面的工具需要前面的地基）。已經有環境的人可以直接從 1 開始。

## 常見問題

**要花錢嗎？** 工具包本身免費。AI 工具（Claude／ChatGPT）的訂閱費另計，用免費額度也能走完大部分；工具 3 的兩條部署路線都有免費方案，會用到付費功能時 AI 會先講清楚。

**我完全不會程式，可以嗎？** 可以，這套就是為此設計的。你負責回答問題和驗收，施工是 AI 的事。

**只有網頁版 Chat、沒有 Claude Code／Codex？** 從工具 0 開始，網頁版 AI 就能陪你把環境裝起來。
