# 工具 1｜基地

## 這個工具給你什麼

一個**會記憶的工作台資料夾**。裝完之後：

- AI 每次開場自動認得你（不用重新自我介紹）
- 你糾正過的事、講過的偏好，會被寫下來，下次還記得
- 做過什麼有紀錄（CHANGELOG）、改壞了回得去（Git 時光機）

> 背後的原理一句話：AI 其實每次開新對話都是失憶的。它會越來越懂你，不是因為記性好，而是因為你把記憶蓋在資料夾裡——它進門第一件事就是讀你留給它的東西。

## 需要先有什麼

- 工具 0（AI 能開資料夾）

## 施工步驟（給 AI 照做）

### 1. 訪談，只問三題

1. 「你大概在做什麼？如果是公司或團隊，大概多大規模？」
2. 「你現在最想讓 AI 幫你解決什麼問題？」
3. 「你希望 AI 跟你合作時是什麼風格？（例如：直接講重點／多解釋一點／做之前先問我）」

他回答後，用一兩句白話複述確認。**不要做身家調查**，三題就好，其他以後用到再問。

### 2. 蓋資料夾

預設蓋在桌面、叫 `AI工作台`（使用者想改名字或位置都依他）：

```
AI工作台/
├── CLAUDE.md        ← 家規（給 Claude 自動讀）
├── AGENTS.md        ← 家規（給 Codex 自動讀，內容與 CLAUDE.md 相同）
├── memory/
│   └── MEMORY.md    ← 記憶索引
├── CHANGELOG.md     ← 做過什麼的流水帳
└── 裝備清單.md      ← 這個工具包的安裝紀錄
```

⚠️ **家規檔名必須就叫 `CLAUDE.md` 和 `AGENTS.md`，不能取別的名字。** Claude Code 開場只自動讀 `CLAUDE.md`、Codex 只自動讀 `AGENTS.md`——取別的名字，「進門自動認得你」就失效了。兩份內容保持一樣，改一份就同步另一份。

### 3. 寫家規（用訪談答案填，寫完唸給使用者確認）

範本（`CLAUDE.md` 與 `AGENTS.md` 都用這份）：

```markdown
# 我的 AI 工作台家規

## 我是誰
（訪談第 1 題的答案，兩三行）

## 我目前最想解決
（訪談第 2 題的答案）

## 合作方式
（訪談第 3 題的答案）

## 讓自己越來越好用（給 AI 的常駐規則）
- 當我糾正你、或講出一個做事偏好時，主動問我：「這條要不要記下來？」
  我同意，就寫成一個檔案放進 memory/，並在 memory/MEMORY.md 加一行索引。
- 每次開場，先看 memory/MEMORY.md 有哪些記憶，碰到相關的事再打開對應檔案。

## 完工（做完一件事就自動做，不用我喊）
- 做完而且真的試過能用，才算完工。還沒完就在 CHANGELOG.md 記「做到哪、下一步是什麼」，不要說做好了。
- 完工時做三件事：CHANGELOG.md 最上面加一段（日期、做了什麼、為什麼）；用 Git 存一版；有裝知識庫的話，照知識庫的規則多做一步。
- 同一件事只收一次，小修改不用每次都跑。

## 先問我再做
- 碰到錢（付費、訂閱、任何會產生費用的服務）
- 刪除或覆蓋我的檔案
- 對外發送任何東西（訊息、郵件、發佈上網）
```

最後那段「先問我再做」是這個工具包作者用真金白銀換來的預設值，先照放；使用者想改再改。

### 4. 建記憶區與 CHANGELOG

- `memory/MEMORY.md` 初始內容：`# 記憶索引\n\n（還沒有記憶。之後每記一條，在這裡加一行：- [標題](檔名.md) — 一句話摘要）`
- `CHANGELOG.md` 第一段就寫今天：裝了基地、日期。

### 5. Git 時光機

1. 檢查電腦有沒有裝 Git（你自己查，不要叫使用者去打指令）。沒裝 → 白話說明 Git 是「檔案的時光機」，帶他裝（或先記進裝備清單待辦，不擋路）。
2. 有 Git → 在工作台 `git init`，把剛建的檔案做第一次 commit：「基地落成」。
3. 跟使用者講一句就好：「以後每個階段我都會拍一張快照，改壞了隨時回得去。」細節不用教。

### 6. 建裝備清單

`裝備清單.md`：

```markdown
# 裝備清單

工具包版本：2026-11-02

- [x] 0 環境（YYYY-MM-DD）
- [x] 1 基地（YYYY-MM-DD）
- [ ] 2 知識庫
- [ ] 3 部署

## 待辦
（例如：Git 還沒裝）
```

## 驗收（一定要真的做）

**測「AI 是不是真的認得他」**：請使用者把目前對話關掉，在工作台資料夾開一個全新對話，問 AI：「你知道我是誰、我在做什麼嗎？」

AI 不需要任何提醒就答得出家規裡的內容 → 基地活了。答不出來 → 檢查檔名是不是正確（`CLAUDE.md`／`AGENTS.md`）、資料夾是不是選對。

## 裝完之後

- **以後所有工作都從這個資料夾開對話**——這是整套的前提。
- 家規不是寫完就死的：AI 被糾正就會問「要不要記下來」，基地會自己越長越懂你。

驗收通過後，跟使用者說：「工具 1 裝好了。今天到這裡，還是繼續裝工具 2（知識庫）？」
