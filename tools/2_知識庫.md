# 工具 2｜知識庫

## 這個工具給你什麼

一個**已經規劃好格局的 Obsidian 知識庫**——不是空白軟體，是開箱就有三個分區、一個首頁、一份放東西的規則，而且 AI 知道怎麼幫你用它。

跟基地的分工：**基地記「工作」**（做過什麼、怎麼合作），**知識庫記「學到什麼」**（為什麼這樣做、下次別再踩的坑、值得留的想法）。

## 需要先有什麼

- 工具 1（基地）
- Obsidian（免費軟體；還沒裝的話施工時一起裝）

## 施工步驟（給 AI 照做）

### 1. 裝 Obsidian（已裝就跳過）

帶使用者到 Obsidian 官網下載安裝（免費，不用註冊帳號也能用）。安裝方式查當下官方說明，不憑記憶指路。

### 2. 把知識庫蓋在基地裡

在工作台資料夾底下建 `知識庫/`（好處：跟基地一起備份、一起進 Git 時光機）：

```
AI工作台/
└── 知識庫/
    ├── 首頁.md        ← 目錄，從這裡出發
    ├── 規則.md        ← 什麼東西放哪裡（人和 AI 都要讀）
    ├── 收進來/        ← 外面撿的：文章重點、別人講的、截圖筆記
    ├── 我寫的/        ← 自己的原始紀錄：會議、想法、決定的原文
    └── 整理好的/      ← 提煉過的重點：學到的方法、踩過的坑、做事的原則
```

`規則.md` 範本：

```markdown
# 知識庫規則

三個分區，照來源放：
- 收進來/ ＝ 外面來的原料（文章、影片重點、別人給的資料）
- 我寫的/ ＝ 我自己產的原始紀錄（會議、想法、決定），原文保留、不改寫
- 整理好的/ ＝ 提煉過的重點，一篇講一件事，篇名讓半年後的自己看得懂

給 AI 的規則：
- 完成一件值得記的工作後，主動問我：「這次的『為什麼』要不要寫進知識庫？」
  我同意，就寫一篇放進 整理好的/，並在 首頁.md 加上連結。
- 寫的時候用 [[檔名]] 連結相關的舊筆記，讓知識長成網。
- 收進來/ 和 我寫的/ 的原文不准改寫，要提煉就另外寫進 整理好的/。
```

`首頁.md` 初始內容：標題＋三個分區的說明各一行＋「最新筆記」清單（先空著）。

### 3. 讓 Obsidian 認得它

帶使用者打開 Obsidian → 「開啟資料夾作為儲存庫」→ 選 `AI工作台/知識庫/`。

### 4. 跟基地接線

在 `CLAUDE.md` 和 `AGENTS.md` 家規裡追加一段：

```markdown
## 知識庫
- 這個工作台有知識庫，在 知識庫/，放東西前先讀 知識庫/規則.md。
- 完成值得記的工作後，主動問我要不要把「為什麼」寫進去。
```

### 5. 寫下第一篇（不留空庫）

當場示範：把「今天裝基地／知識庫的過程和原因」寫成第一篇，放進 `整理好的/`，並掛上首頁。讓使用者親眼看到一篇筆記從無到有。

## 驗收（一定要真的做）

1. 使用者打開 Obsidian，看得到首頁、三個分區、第一篇筆記。
2. 點首頁上的連結，能跳到那篇筆記。

## 裝完之後

- 平常不用刻意「寫筆記」——AI 做完事會主動問要不要記，你點頭就好。
- 更新 `裝備清單.md`，然後問使用者：「今天到這裡，還是繼續裝工具 3（部署）？」
