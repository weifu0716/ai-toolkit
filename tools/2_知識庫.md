# 工具 2｜知識庫

## 這個工具給你什麼

一個**已經規劃好格局的 Obsidian 知識庫**——不是空白軟體，是開箱就有三個分區、一個首頁、一份放東西的規則，而且 AI 知道怎麼幫你用它。裝到最後還會接上你的瀏覽器：網路上看到好文章，**按一下就存進知識庫**，之後跟 AI 說一聲「整理知識庫」，它就幫你消化成重點。

跟基地的分工：**基地記「工作」**（做過什麼、怎麼合作），**知識庫記「學到什麼」**（為什麼這樣做、下次別再踩的坑、值得留的想法）。

## 需要先有什麼

- 工具 1（基地）
- Obsidian（免費軟體；還沒裝的話施工時一起裝）

## 施工步驟（給 AI 照做）

### 1. 裝 Obsidian（已裝就跳過）

帶使用者到 Obsidian 官網下載安裝（免費，不用註冊帳號也能用）。安裝方式查當下官方說明，不憑記憶指路。

### 2. 把知識庫蓋在基地裡

在工作台資料夾底下建 `知識庫/`（好處：跟基地一起備份、一起進 Git 時光機）：

```
AI工作台/
└── 知識庫/
    ├── 首頁.md        ← 目錄，從這裡出發
    ├── 規則.md        ← 什麼東西放哪裡（人和 AI 都要讀）
    ├── 收進來/        ← 外面撿的：文章重點、別人講的、截圖筆記
    ├── 我寫的/        ← 自己的原始紀錄：會議、想法、決定的原文
    └── 整理好的/      ← 提煉過的重點：學到的方法、踩過的坑、做事的原則
```

`規則.md` 範本：

```markdown
# 知識庫規則

三個分區，照來源放：
- 收進來/ ＝ 外面來的原料（文章、影片重點、別人給的資料）
- 我寫的/ ＝ 我自己產的原始紀錄（會議、想法、決定），原文保留、不改寫
- 整理好的/ ＝ 提煉過的重點，一篇講一件事，篇名讓半年後的自己看得懂

給 AI 的規則：
- 完成一件值得記的工作後，主動問我：「這次的『為什麼』要不要寫進知識庫？」
  我同意，就寫一篇放進 整理好的/，並在 首頁.md 加上連結。
- 寫的時候用 [[檔名]] 連結相關的舊筆記，讓知識長成網。
- 收進來/ 和 我寫的/ 的原文不准改寫，要提煉就另外寫進 整理好的/。
```

`首頁.md` 初始內容：標題＋三個分區的說明各一行＋「最新筆記」清單（先空著）。

### 3. 讓 Obsidian 認得它

帶使用者打開 Obsidian → 「開啟資料夾作為儲存庫」→ 選 `AI工作台/知識庫/`。

### 4. 跟基地接線

在 `CLAUDE.md` 和 `AGENTS.md` 家規裡追加一段：

```markdown
## 知識庫
- 這個工作台有知識庫，在 知識庫/，放東西前先讀 知識庫/規則.md。
- 完成值得記的工作後，主動問我要不要把「為什麼」寫進去。
- 當我說「整理知識庫」：讀 收進來/ 裡還沒消化過的筆記，先跟我確認哪些值得留，
  再把值得留的提煉成重點寫進 整理好的/（一篇講一件事）、用 [[檔名]] 連結相關舊筆記、
  更新 首頁.md 的最新筆記清單。原文留在 收進來/ 不動。
```

### 5. 寫下第一篇（不留空庫）

當場示範：把「今天裝基地／知識庫的過程和原因」寫成第一篇，放進 `整理好的/`，並掛上首頁。讓使用者親眼看到一篇筆記從無到有。

### 6. 接上瀏覽器（Obsidian Web Clipper，一鍵剪文章）

跟使用者講一句就好：「裝完這個，以後在網路上看到好文章，按一下就存進知識庫，不用複製貼上。」

⚠️ 這段的對象是**完全新手**：一步只做一件事，每步都等他說「好了」再往下，不要一次丟五個步驟。介面按鈕文字會隨版本變，卡住就以官方頁面當下的畫面為準、白話翻給他聽。

1. **裝擴充功能。** 請他用平常上網的瀏覽器打開這個網址（獨立唸給他、或請他自己打）：

   https://obsidian.md/clipper

   頁面上按「Add to Chrome」（用 Edge／Safari／Firefox 的話，往下捲有 More browsers 區、選自己的那顆）→ 跳到擴充功能商店後按「加到 Chrome」→ 跳出確認視窗按「新增擴充功能」。
2. **把它釘出來，不然下次找不到。** 瀏覽器右上角的**拼圖圖示**點開 → 找到 Obsidian Web Clipper → 按旁邊的**圖釘**。之後工具列會一直看得到 Obsidian 的小圖示。
3. **設定存去哪（只要做這一次）。** 點那個小圖示 → 找**齒輪（設定）**：
   - Vault（儲存庫）：填 Obsidian 裡開的儲存庫名稱，照第 3 步裝的預設就是 `知識庫`。
   - 存放位置（Note location）：填 `收進來`。
   - 其他設定都不用動。
4. **實剪一篇。** 請他隨便開一篇網路文章（新聞、部落格都行）→ 點小圖示 → 按儲存。第一次會跳出「要開啟 Obsidian 嗎？」→ 按允許。⚠️ 前提：Obsidian 要開著（或至少開過這個儲存庫一次），沒開就先開。
5. **回 Obsidian 看。** `收進來/` 裡多了那篇文章 → 通了。沒出現 → 回設定檢查儲存庫名稱是不是打錯字（要跟 Obsidian 左上角顯示的一模一樣）。

### 7. 當場示範一次「整理知識庫」

第 4 步接線時，家規裡已經加了「整理知識庫」的規則。現在就用剛剪進來的那篇當教材，真的跑一次給使用者看：

1. 請使用者跟你說：「整理知識庫」。
2. 你照家規做：讀剛剪的那篇 → 問他「這篇值得留嗎？重點是什麼？」→ 提煉成一篇短筆記寫進 `整理好的/` → 掛上首頁。
3. 跟他講清楚這個習慣：「以後平常看到什麼就剪什麼，不用整理；每週想到的時候跟我說一聲『整理知識庫』，我就幫你消化一輪。」

## 驗收（一定要真的做）

1. 使用者打開 Obsidian，看得到首頁、三個分區、第一篇筆記。
2. 點首頁上的連結，能跳到那篇筆記。
3. 在瀏覽器剪一篇文章，`收進來/` 真的出現它。
4. 使用者說「整理知識庫」，AI 真的把它消化成一篇進 `整理好的/`。

## 裝完之後

- 平常不用刻意「寫筆記」——看到好東西就剪，AI 做完事也會主動問要不要記，你點頭就好。
- 養成一個小習慣：每週跟 AI 說一聲「整理知識庫」，收進來的東西才不會變垃圾山。
- 更新 `裝備清單.md`，然後問使用者：「今天到這裡，還是繼續裝工具 3（部署）？」
